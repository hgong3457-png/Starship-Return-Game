# **游戏设计说明**

## **一、 故事源起**

百年前人类派出了一艘深空勘探舰“空旅号”，去探索宇宙中有生命迹象的世界，却意外遭遇宇宙灾害从此失联，自此在星际间孤独漂泊了百年之久。如今的船员已是当年的后代，从小在太空中长大，只知道传说里有“母星地球”。有一天飞船在常规扫描时，突然捕捉到微弱的无线电信号，解码后发现竟然跟他们所说的语言相同--地球的通用语言。尘封百年的故土音讯重现，让全员震动。于是飞船立刻调转航向，火速踏上归乡之路。

## **二、 程序整体架构与运行流程**

本项目基于 C/C++ 与 EasyX 图形库开发。程序启动后首先进入独立的 ShowMenu() 主菜单先阻挡住循环，检测玩家的鼠标交互（开始游戏or查看说明）。一旦接收到启动指令，程序立即释放菜单资源，加载底层宇宙背景，并进入核心的 while(1) 游戏主循环。

游戏核心实现部分的主循环，严格遵循“输入处理--物理与逻辑更新-- 双缓冲图形绘制--帧率控制”的标准游戏开发流水线，确保了游戏运行的流畅体验。

## **三、 核心量化指标与参数设定**

游戏内所有实体（星空，星球，障碍物，子弹，粒子）均采用了 **3D伪透视坐标系 (x, y, z)** 进行管理。以下是代码中编码的核心数值体系：

### **1. 宇宙天体与障碍物生成指标 (最大同屏数量: 10)**

为了尽可能还原真实的宇宙环境，程序通过随机数分配了三种层级的障碍物，具体数值如下：

( PS:由于水平有限，本想采用真实的不规则形态的贴图去模拟陨石/冰晶/太空垃圾等小型障碍物。但为了便于确定物体大小，以考虑万有引力这一因素，最终本游戏中所有物体均用标准球体模拟，从而通过判断半径范围得到物体大小范围 )

* **黑洞** ：

  * **生成概率**：5%
  * **半径范围**：60 \~ 79 像素
  * **威胁等级**：极高（无论此时多少血量（盾护值），触碰则直接清空从而 GAME OVER）
* **巨型星球** ：

  * **生成概率**：45%
  * **半径范围**：40 \~ 54 像素
  * **威胁等级**：中（触碰扣除 2 点护盾值）
* **小型陨石 (Small Rock)**：

  * **生成概率**：50%
  * **半径范围**：15 \~ 34 像素
  * **威胁等级**：低（触碰扣除 1 点护盾值。可被子弹击毁，击毁+50分）

### **2. 运动学与速度指标 (基于每帧更新)**

* **飞船机动速度 (横向/纵向)**：14.0f 像素/帧 (WASD 控制)
* **星空背景后退速度**：18.0f 像素/帧（营造基础的曲率飞行速度感）
* **星球逼近速度**：15.0f 像素/帧（稍慢于星空，形成视差效果）
* **子弹飞行速度**：60.0f 像素/帧（高速射出，确保打击感）

### **3. 纵深 (Z轴) 场域设定**

* **视场近切面**：z = 1.0f（小于此距离的物体会被移出屏幕并重置）
* **星空生成远切面**：z = 1200.0f \~ 1599.0f
* **星球/障碍物生成远切面**：z = 1500.0f \~ 2499.0f（后期调整：特意推远生成距离，解决 3D 游戏中常见的“物体突然贴脸刷出”的穿帮问题）

## **四、 核心物理模型与设计的小巧思**

### **1. 动态万有引力衰减模型**

游戏为半径 >= 40.0f 的大型天体（巨型星球和黑洞）赋予了引力场。此半径以下则忽略了对星际飞船的引力作用。为了让引力显得真实，程序设计了一个基于距离的双重衰减数学模型：

* **引力触发阈值**：只有当飞船与天体的 Z 轴深度距离 < 800.0f（前进方向距离），且 2D 平面距离 < 600.0f 时（xoy平面上的距离），才会受到引力牵引。
* **引力强度设计**：**黑洞**的基础引力常数为 20.0f，**巨型星球**为 10.0f。
* **距离衰减公式**：引力值 = 基础引力 \* (1 - z/800)² \* (1 - 2D距离/600)²。该非线性二次方衰减公式保证了飞船越靠近天体，被吸入的拉力**呈现指数级增长**，极大地增强了真实压迫感。

### **2. 射击与碰撞判定系统的巧思**

* **对象池技术** ：内存中预先分配了 8 颗子弹 (MAX\_BULLETS)，在射击时遍历寻找： active == 0 的闲置子弹进行复用，避免了运行中频繁的 new/delete 内存分配开销。
* **射击冷却机制** ：设有 shootTimer 变量，每次射击后重置为 8 帧，防止玩家按住空格键导致子弹连发重叠，平衡了游戏难度。
* **宽容的碰撞体积 (Hitbox Leniency)**：在 3D 转 2D 的投影碰撞计算中，采用了 0.9f 的判定系数（即碰撞半径缩小至 90%）。这一巧思防止了边缘像素级别的“擦边误判”，显著提升了玩家的射击手感。

### **3. 3D 伪透视投影与星球渲染**

* **透视除法**：全屏采用 常数 / Z轴坐标 的缩放因子 (f = 400.0f / z)。物体的屏幕坐标系 (x, y) 和绘制半径都乘以该系数，完美还原了“近大远小”的 3D 透视规律。
* **星球渲染**：在绘制带核心的星球时，采用了 switch (i % 5) 的余数分配法，为星球的内芯添加了四种不同方向的固定偏移量，增强了天体的自然感。

### **4. 粒子系统与屏幕震动** 

* 为了强化打击反馈，当小型陨石被击碎时，会在其三维坐标处爆发 15 个碎片粒子。粒子的初始速度系随机生成（X/Y轴方向 -20\~20，Z轴 -5\~5），生命周期 20\~29 帧。
* 飞船受击时，不仅会扣除生命值，还会导致全屏幕随机偏移震荡 (shakeTime = 20)，大大提升了沉浸感。当护盾值只剩最后一格时，会触发红屏闪烁警告 (hitFlash = 5) 。
